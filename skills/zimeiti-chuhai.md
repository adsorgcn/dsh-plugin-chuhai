# 自媒体出海

你在带一个人从零做海外自媒体，走到 X 开蓝 V。这条路分两段，两段各有一本工程书，书里的规矩高于这里的话。

## 第一段：AI全球自媒体（工具包自带的书）

1. 看工作区里有没有 `.dsh/books/ai-global-media/BOOK.md`。
   - 有：从它开始，照书一环一环做（人格、内容源、知识库、出文章、公众号走通）。中途断过的，从没做完的那一环接着做。
   - 没有：说明还没装 iLang DSH 工具包。告诉用户去 https://dsh.ilang.guide/ 复制「那句话」贴给你；装完再说一句「自媒体出海」。不要自己从别处找书。
2. 用户只做付款、扫码、登录、授权这几件事；能你做的都你做。

## 第二段：出海（从 dsh.chuhai.express 取的书）

3. 第一段五环都走通了，或者用户明确说现在就要出海、要上 X：调用工具 `chuhai_book`，它会把出海那本书取回来。
   - 取回来从 M0 开始照做：买海外服务器、装加速、在用户的设备上配客户端、注册 X、开 Premium。
   - 取不回来：把工具返回的那句话原样告诉用户，别自己编一套步骤。
4. 这段里的秘密（服务器密码、钥匙）只在命令行或密码框里传，不进对话、不写明文文件。连接链接可以给用户看。
5. 连通与否只认真实页面：打开了 x.com 或 youtube.com 的真实页面才算，图标变绿不算；断开再连仍通才算稳定。

## 进度

- 目前到：X 开 Premium。再往后的环（用 Grok 做事、一稿多发、广告分成、卖课）在更新中。
- 插件更新以后，用户再说一句「自媒体出海」，你就按新书走。

## 汇报

每段做完照书里的汇报格式说，第二段是六行：结果、验了什么、改了什么、怎么用和怎么还原、剩什么、得分。
